# 状态图普查数据

这批数据是对**所有 4×4 以内谜题**（长宽各取 2、3、4，滑动距离 step 取 1 到较小的边长，共 22 个）
做的一次**完整状态图普查**：把每一个谜题的**全部合法局面**一个不漏地枚举出来，
再把局面之间所有合法的一步滑动连成有向边，最后逐个局面记录它属于哪些集合、离还原态有多远。

数据总量约 **70 KB**，全部是汇总统计（不含原始逐局面数据）。

---

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `ALL_SUMMARY.csv` | 22 个谜题的总表，一行一个谜题，含各集合大小、最难步数、边数等 |
| `distance_distribution.csv` | 距离分布：长表，每行是「某个谜题 + 某个步数 + 该步数下的局面数」 |
| `outdegree_distribution.csv` | 出路条数分布：长表，每行是「某个谜题 + 几条合法走法 + 这样的局面有多少个」（0 条即死局） |
| `arrow_direction.csv` | 箭头方向统计：每个谜题的箭头总数里，多少是双向（能原路退回）、多少是单向 |
| `subgraph_4x4x2.json` | 从 `4x4x2` 真实状态图里切出的一小片：86 个真实局面 + 它们之间的真实有向边，含每条边是否双向 |
| `per_puzzle/<谜题>/summary.txt` | 单个谜题的完整统计（比总表多几项，如两种死局口径的对照） |
| `shape_phi.csv` | **形状指标**：按剖面缺陷 Φ 分档，长表「谜题,Φ,局面数,可还原数,平均步数」 |
| `shape_gather.csv` | **形状指标**：按聚拢度分档，长表「谜题,聚拢度,局面数,可还原数,平均步数」 |
| `shape_bbox.csv` | **形状指标**：按边界盒尺寸分档，长表「谜题,高,宽,局面数,可还原数,平均步数」 |
| `phi_samples_4x4x2.json` | 按 Φ 分档抽出的**真实局面样本**（`rows` 是 16 个行位掩码），页面上「形状画廊」用的就是它 |

谜题命名是 `长x宽xstep`，例如 `4x4x2` 是 4×4 的板、每次滑动 2 格。

## 字段对照（通俗说法 ↔ 原始文件里的记号）

原始统计文件是在研究过程中生成的，沿用了一些内部记号。下表说明它们分别对应什么：

| 原始记号 | 通俗含义 |
| --- | --- |
| `\|A\|` | **全部合法局面**（所有能摆出来的长相）。这就是「着色集合」，是本页一切数字的分母 |
| `\|cone\|` | 从还原态出发**走得到**的局面数（去程可达） |
| `\|B\|` | **能走回还原态**的局面数（回程可达） |
| `可解 cone∩B` | 既走得到、又回得来——真正可还原的局面 |
| `god` | **最难还原步数**：所有可还原局面里，离还原态最远的那个要几步 |
| `真死局 sink` | **一步都走不动**的局面（没有任何合法滑动）。这是真正的死局 |
| `cone\B` | 走得去、但回不来的局面（注意：它**还能动**，不是死局） |
| `吸引盆` | 顺着箭头走，最终会掉进死局的局面数 |
| `两不沾` | 既回不到还原态、也走不到死局，只能在小块里原地打转的「孤岛」 |
| `edges` | 状态图里的箭头总数 |

### 形状指标（`shape_*.csv`）

这三个指标都**只看一个局面的外形**，与它怎么走无关：

| 指标 | 通俗含义 |
| --- | --- |
| 聚拢度 | 拿一个「还原态那么大的矩形框」去套，最多能盖住几格。盖满就是还原态 |
| 边界盒（高×宽） | 能框住它的最小矩形有多大 |
| 剖面缺陷 Φ | 数一数每行、每列各有多少格，看离「整整齐齐」偏了多少，把偏差全部加起来。0 表示形状正好是还原态那块矩形 |

> 关于死局的口径：早期笔记曾把「走得去却回不来」称作死局，那是**不对的**——那种局面还能动，只是回不去。
> 真正的死局是**一步都走不动**，本数据一律采用这个口径。

## 距离分布怎么读

`distance_distribution.csv` 每行 `谜题,步数,局面数`。把某个谜题的所有行画出来，
横轴是「离还原态还要几步」，纵轴是「有多少个局面正好要这么多步」，会得到一条**钟形曲线**：
绝大多数局面集中在中间某个步数附近，要 0 步（就是还原态本身）和要走满最难步数的都极少。

以 `4x4x2` 为例：最难是 **17 步**，但 55 万多个局面里，只有 **1 个**需要 17 步；
绝大多数落在 **8～10 步**，峰值在 9 步（140,771 个局面）。

## 箭头方向：单向箭头其实不少，但基本不致命

`arrow_direction.csv` 给出一个容易误解的事实：以 `4x4x2` 为例，全部 **4,270,552** 支箭头里，

- **3,389,400** 支（79.4%）成对出现，可以原路退回（双向）；
- **881,152** 支（20.6%）是单向的，走过去就回不来。

单向箭头占了**两成**，并不罕见。但关键在于：绝大多数单向箭头只是「这条路原路退不回」，
绕个远照样能回到原处。真正因为踩上单向箭头而**彻底回不去还原态**的局面，只占全部局面的极小一部分。

`subgraph_4x4x2.json` 里那 86 个局面的一小片可以直接验证这一点：41 支单向箭头中，
**40 支**两端仍在同一片互通区域里（绕远能重逢），只有 **1 支**是真正通向死局、一去不返。

## 这些数据是怎么算出来的

用开源的普查程序**穷举**得到，不是抽样、不是估计：
先枚举全部合法局面，再建出完整的正向/反向邻接表，然后从还原态做正向与反向的广度优先搜索，
逐个局面记录归属与距离。每个局面属于哪个集合，都有逐条记录。

形状指标（聚拢度 / 边界盒 / 剖面缺陷 Φ）也是在同一次穷举里逐局面算出来的，
不是抽样：以 `4x4x2` 为例，559,832 个局面每一个都算了这三个数。

原始逐局面数据体积很大（单个谜题可达数百 MB），不适合放进网页仓库；
如需完整原始数据，可用同款开源普查程序自行重算（结果可复现）。

## 形状指标里最干净的两条规律（`4x4x2`）

- **剖面缺陷 Φ 的生死线**：Φ ≤ 30 的 559,512 个局面里，只有 1,291 个回不去（99.77%）；
  而 Φ ≥ 32 的 320 个局面里，有 264 个回不去（只剩 17.5%）。Φ = 36、38 的 8 个局面**全部**回不去。
- **边界盒宽度 2 格 = 必死**：边界盒宽只有 2 格的 **264** 个局面，**可还原数为 0，一个例外都没有**。
  最窄边 3 格 → 99.22%；4 格 → 99.71%；5 格 → 99.71%；6 格 → 99.85%；7 格 → 99.97%；8 格 → 100%。

两条规律其实是同一件事：一个「2 格宽」的形状，行列剖面必然歪得离谱，
这 264 个局面的 Φ **无一例外都 ≥ 32**。

留意：这两条只在**滑动距离 2** 的谜题里这么锋利。`4x4x1`（每次推 1 格）里 Φ 一直到 42 都还是 100% 可还原
（13,079,255 个局面里只有 1 个回不去）；`4x4x3`（每次推 3 格）里整体都难，Φ 反而失去区分度。
