貓九的滑塊遊戲 GatenneaSlider

分類：單機・益智・燒腦・競速
▶ 進入遊戲

這是什麼遊戲？

這是貓九製作的第二款原創規則遊戲。玩家（或 AI）透過「選縫隙 → 選滑塊組 → 滑動」把打亂的方塊還原成一個完整的實心長方形（允許整體平移或旋轉方向，不是回到初始版面）。

它的難度非常高，適合邏輯思維強的人挑戰。

支援平台：瀏覽器 / Windows 系統 / Python + pygame 環境。

遊戲規則

  • 縫隙：方塊之間的空隙通道，分為橫向與縱向。
  • 一次完整移動：選縫隙 → 選滑塊組 → 移動。
  • 還原條件：把所有方塊拼成任意位置、任意方向的完整實心長方形。

操作方式

  • 滑鼠/桌上型：點縫隙 → 點方塊 → W/A/S/D 或拖拽滑動；也可直接拖拽滑塊，依拖拽方向判定縫隙與滑動方向。
  • 手機/觸控：支援單次觸控（直接拖拽即滑動）、兩次觸控、虛擬鍵盤，也支援兩指捏合縮放與拖拽平移地圖。
  • 控制模式：單次觸控、兩次觸控、鼠標鍵盤控制可任意開關。

功能

  • 撤銷 / 重做 / 重置 / 自動打亂
  • 練習模式與競速計時、DNF、成績面板（Ao5 / Ao12）
  • 存檔：電腦可用原版格式 .json；手機可用瀏覽器內存檔列表
  • 多種尺寸與難度的謎題
  • 鼠標滾輪 / 兩指捏合縮放，視圖可平移
  • 動畫：滑動動畫、選中動畫、撤銷/重做動畫佇列

下載連結

貓九把遊戲的不同部分拆成多個連結，供不同需要的人下載。

版本說明：核心上就是兩種架構，Web 版和 Python 版。

說明：資料庫指的是遊戲功能「查表求解器」執行時需要的資料；若缺失，該求解器無法使用。因為它不是核心功能，且與遊戲更新互不相干，所以專門提供連結。

猫九的滑块游戏 GatenneaSlider

分类：单机・益智・烧脑・竞速
▶ 进入游戏

这是什么游戏？

这是猫九制作的第二款原创规则游戏。玩家（或 AI）通过「选缝隙 → 选滑块组 → 滑动」把打乱的方块还原成一个完整的实心长方形（允许整体平移或旋转方向，不是回到初始版面）。

它的难度非常高，适合逻辑思维强的玩家挑战。

支持平台：浏览器 / Windows 系统 / Python + pygame 环境。

游戏规则

  • 缝隙：方块之间的空隙通道，分为横向缝隙和纵向缝隙。
  • 一次完整移动：选缝隙 → 选滑块组 → 移动。
  • 还原条件：把所有方块拼成任意位置、任意方向的完整实心长方形。

操作方式

  • 鼠标/桌面：点缝隙 → 点方块 → W/A/S/D 或拖拽滑动；也可以直接拖拽滑块，根据拖拽方向判定缝隙与滑动方向。
  • 手机/触控：支持单次触控（直接拖拽滑动）、两次触控、虚拟键盘，也支持双指捏合缩放与拖拽平移地图。
  • 控制模式：单次触控、两次触控、鼠标键盘控制可自由开关。

功能

  • 撤销 / 重做 / 重置 / 自动打乱
  • 练习模式与竞速计时、DNF、成绩面板（Ao5 / Ao12）
  • 存档：电脑可用原版格式 .json；手机可用浏览器内存档列表
  • 多种尺寸与难度的谜题
  • 鼠标滚轮 / 双指捏合缩放，视图可平移
  • 动画：滑动动画、选中动画、撤销/重做动画队列
