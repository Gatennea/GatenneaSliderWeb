# 网页版功能清单

> **这份清单逐项对着代码核实过**，不是凭印象写的。它回答一个问题：「网页版现在到底有哪些功能」。
>
> 维护约定：
> 1. 增删任何**玩家看得见**的功能时，同步改这里；
> 2. 任何人（包括 AI）提议新功能之前**先查这份清单**——已经提议过一次「加键盘操作」，
>    结果 `BoardController.onKeyDown` 早就支持方向键/WASD 连续推了，纯属重复造轮子。
>
> 基准：`main` 分支。尚在分支上、未合入的功能统一记在最后一节「分支地图」。

## 1. 跑起来

零构建工具链：`tsc` 编译到 `dist/`，自写 `scripts/bundle.mjs` 把产物合成单文件 IIFE `app.js`。
`game.html` 直接双击（`file://`）就能开，不需要服务器。

| 命令 | 作用 |
| --- | --- |
| `npm run build` | `tsc` + `bundle`（含打包器保险，见第 13 节） |
| `npm test` | 跑 `scripts/run-tests.mjs`（无依赖、in-process） |
| `npm run dev` | 本地调试服务器 + `/api/*` 调试端点 |
| 双击 `start.bat` / `dev.bat` | 前者构建后开 `game.html`，后者构建后起服务器 |

> 之前黑屏的常见原因：`dist/` 没编译，或旧 `game.html` 用了 `<script type="module">`（被 file:// CORS 拦）。现在已是单档 IIFE。

## 2. 谜题规格与形态

**已实现**

| 项 | 说明 |
| --- | --- |
| 方形 m×n | 菜单「谜题」：4×4 ~ 10×10 全覆盖 |
| 步长 step | 2 与 3 两档（`2~6*6` / `3~6*6` 这种写法 = step~m*n） |
| 自定义 | 「自定义...」可指定 m/n/step |
| 数字形态 | 方块编号（按行主序 1..m*n），**单独算一组成绩**（分组键后缀 `#num`） |
| 创造模式 | 自定义目标形状（随机挖缺口，或 12×12 手动构造），`solutionMask` 虚影提示 |

**未实现（菜单里带「完整版」标记，点了会弹提示）**

- 三角形态、米字形态
- 宏录制/播放（开始录制、停止录制、宏列表、播放宏、逆序播放）
- 快捷键设置
- 自动求解（`main` 上没有，见第 12 节的 `feat/solver-gather` 分支）

## 3. 交互

一套棋子，四種操作入口，彼此是同一条命令链（`selectGap` → `selectBlock` → `move`）：

| 入口 | 现状 | 备注 |
| --- | --- | --- |
| 鼠标点选 | 点缝 → 点方块 → 点箭头；右键取消选中 | 箭头是复刻原版 `arrow_B.png` 内联过来的，走不通的方向不显示 |
| 键盘推动 | **已有**：选中缝+组之后方向键 / WASD 推动，**移动后保留选中以便连续推** | `BoardController.onKeyDown` + `DIRECTION_KEYS` |
| 单次触屏拖拽 | 不用先选缝，按拖拽角度判 8 区方向；完成后清空选中 | `singleTouchEnabled` |
| 两次触屏 | 先点缝、再点组 | `twoTouchEnabled` |
| 虚拟键盘 | F1 或「设置 → 虚拟键盘」呼出浮层：方向键 + 粘滞/撤销/重做 + 跳到某步 | 尺寸对齐原版（206 宽）；可拖动且会被夹在画面内；**触屏设备默认开着**（手机没实体方向键） |
| 常驻撤销/重做条 | 屏幕左下角常驻「↶ 撤销 / ↷ 重做」，不能撤销时置灰 | 手机端不必先调出虚拟键盘；新手引导条出现时会自动上移让位 |

还有点击涟漪反馈（380ms / 34px / 最多 12 个）。

## 4. 菜单树

```
文件   打开 Ctrl+O │ 保存 Ctrl+S │ 另存为... │ 存檔列表...
编辑   撤销 Ctrl+Z │ 重做 Ctrl+X │ 打乱 Alt+S │ 重置 Ctrl+R
谜题   矩形谜题 ▸ │ 异形谜题 ▸ │ 自定义... │ 模式:练习/竞速/创造 │ 数字形态开关
宏定义 [完整版] 开始录制、停止录制、宏列表、播放宏、逆序播放
设置   虚拟键盘 │ 成绩面板 │ 控制模式... │ [完整版] 求解器...、快捷键设置...
搜索   命令面板 Ctrl+K（把所有菜单命令摊平成可过滤清单；手机没有 Ctrl+K，这里是唯一入口）
帮助   关于 │ 新手引导 │ 玩法詳解 │ 更新日誌
教程   章节教程（新手教程 6 章 24 关）
官网   打开官网
```

「谜题 → 矩形谜题 ▸」是二级子菜单，带分组标题（等级1 入门 / 等级2 经典★推荐 /
等级3 复杂）、当前档位画 ✓、底部「当前：4×4 等级2」；异形谜题里只有数字形态网页版做得到。
命令清单由菜单数据自动生成，加菜单项不必再维护第二份清单。

「控制模式...」里三个开关：单次触屏、两次触屏、鼠标键盘（键盘推动）。
（原版有五个开关，还差虚拟键盘与箭头按键的独立开关，见 `docs/remediation-plan.md` 第 5 项。）

## 6. 快捷键

| 键 | 作用 |
| --- | --- |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| Ctrl+Y、Ctrl+X | 重做（X 与原版同键） |
| Ctrl+S / Ctrl+O | 存盘 / 打开存档 |
| Ctrl+R | 重置 |
| Alt+S | 打乱 |
| 空格 | 竞速模式下开始计时 |
| Ctrl+K | 命令面板（同「搜索」菜单） |
| F1 / F3 | 虚拟键盘 / 成绩面板 |

| Enter | 复原弹窗上 = 保存存档 |
| 方向键 / WASD | 推动当前选中的组（连续按可连续推） |

## 7. 玩法模式

- **练习**：自由滑动，不计时，不计成绩
- **竞速**：打乱后按空格开始，还原即计入成绩；未完成就重置/打乱 → 记一条 DNF
- **创造**：自定义目标形状

6 章结构齐全（含章标题节点）。**目前可玩的 19 关**：第 1 章 1 关、第 2 章 3 关、第 3 章 4 关、

逐关「看解法」回放走的是**历史快照重放**，不是重模拟 `move_info`：存档里 `step` 与

## 13. 工程约定

- **打包器只认语法子集**：单行具名 import、顶层具名 export。写过不了的写法时，
  2026-10-19 起会在写出 app.js 之前报错中止（`node --check` 已内建，不用手敲）。
- **file:// 下无法 fetch 本地 JSON** → 大块数据由 `scripts/gen-*.mjs` 生成内联 TS 常量。
- Node 测试环境没有 `Image` → 载图处要加 `typeof Image === 'undefined'` 守卫，否则测试全崩。
- 教程数据必须以「紧凑 JSON 字符串 + `JSON.parse`」存，不能改回带缩进的对象字面量（体积差约 6 倍）。
