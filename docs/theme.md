## 3. 繪製順序（原版 `draw_board` 層次，照做）

1. 填充 `background`。
2. 繪無限網格 `grid`（以 `cell_size + gap_width` 為週期描空心框）。
3. **先畫選中的 h/v 縫隙線**（紅色，線寬 3）→ 再畫未選中縫隙（灰色）。
4. 繪滑塊：填充 `block`（淡藍）或 `block_selected`（亮綠）→ 圓角 5×zoom → 描邊 `border` 寬度 2×zoom。
5. 連鎖提示（體驗版跳過）：對同組格做 `_lighten` 提亮（向白靠攏，不疊半透明層）。
6. 宏基準標記（體驗版不做）。

## 4. 動畫手感

- 緩動：`ease_out(t) = 1 - (1 - t)^2`（quadratic ease-out）。
- 整組滑塊用**統一偏移量**平移（原版 `anim_map`），避免組內抖動。
- 點擊縫隙即高亮；點一側方塊瞬間標亮整組綠色。

## 5. 字型與文案

- 無襯線；**必須支援繁體中文**。
- 狀態欄左側：`狀態：復原` / `狀態：未復原`（`solved` / `unsolved` 色）。
- 狀態欄：`步數：N`、`謎題：{step}~{m}*{n}`。
- 選單五項：`文件 / 編輯 / 謎題 / 宏 / 設置`（體驗版宏項置灰但保留名字）。
- 右側開關文案：`滑动动画 / 选中动画 / 着色 / 连锁 / 模式:竞速|练习`。
